## 🏢 Executive Overview

**Transport Of India Logistics Solution (TILS)** connects key Indian industrial hubs, manufacturing plants, dry ports, and maritime terminals. 

* **Primary Logistics Hub**: Coimbatore, Tamil Nadu (with direct transport corridors to Chennai, JNPT Mumbai, Tuticorin, Bengaluru, and Pune).
* **Core Capabilities**: Full Truckload (FTL), Heavy Machinery / Over-Dimensional Cargo (ODC), Container Drayage, Port Clearance Integration, and Real-Time IoT Fleet Tracking.
